Instalasi database baru:
1. Buat database jermate_chess_academy.
2. Import file schema.sql melalui phpMyAdmin.
3. Login awal: admin / admin123.
4. Ganti password admin setelah login.

Jika database sudah berisi data dari jermate_chess_academy.sql, jangan import schema.sql ulang. Gunakan database yang ada dan pastikan konfigurasi Backend/config/koneksi.php sesuai.
